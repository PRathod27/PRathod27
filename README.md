### 🚀 Featured Projects

#### 🤖 AI Code Review & Repository Automation System
`React` `FastAPI` `Groq LLM` `GitHub Webhooks` `MongoDB` `Docker`

An event-driven automation platform that removes the manual grind of reviewing every commit and PR. It listens to real-time GitHub repository events via webhooks, processes them asynchronously through a FastAPI backend, and uses Groq-hosted LLMs to generate AI-powered code summaries, review feedback, and issue recommendations — all surfaced through a React dashboard, with events persisted in MongoDB and services containerized with Docker for a clean, decoupled architecture.

#### 🛡️ Distributed Rate Limiter & API Gateway
`Node.js` `Express` `Redis` `Docker`

A distributed rate-limiting gateway built from scratch around the token bucket algorithm, using Redis as shared state so limits stay consistent across multiple gateway instances. Includes fail-open/fail-closed fault-tolerance strategies for Redis outages, with throughput and limit accuracy validated under concurrent load.

#### 🛒 AI-Powered Multi-Agent E-Commerce Platform *(MCA Project)*
`Next.js` `TypeScript` `Express` `FastAPI` `PostgreSQL + pgvector` `Redis/BullMQ` `LangChain/LangGraph` `Docker`

A full-stack e-commerce platform powered by a multi-agent architecture — a central orchestrator delegates work to five specialized agents (shopping, recommendation, comparison, review, and support). Agents interact with data only through controlled tools/APIs exposed by the backend, never touching the database directly, keeping the system secure and modular.
